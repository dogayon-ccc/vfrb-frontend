# Toolkit changes 2026-11-22 (audit of Pilot 01)
Evidence (source GLB aed377b3...): single watertight closed shell, 47,491 v / 94,990 tri, NO UVs, Euler -4 (thick cloth, outer+inner wall).
Ray test: ~45% of faces are inner-wall. Old normal-sign front/back rule: front panel 41.7% inner, back 47.4% inner. New rule (depth-side + viewer-facing): 4.3% / 8.7% (residual = armpit/fold misclassification in the proxy test).
1. Units: *_m / "metre" renamed to *_mu / "model_units_uncalibrated". No physical scale is claimed.
2. mathcore: front/back chosen by POSITION (depth mid-plane), not normal sign; cylinder wrap uses one reference radius so inner+outer walls share UVs.
3. derive_2d: outline faces = correct depth side AND viewer-facing; clear error if a view has none. Relies on outward winding (source verified: volume > 0).
4. validate: UV rule = no texel with >2 layers (outer+inner wall = 2 expected); reports double-wall %. Partition check replaced by honest "outline faces <= part tris".
5. verify(): now returns pass_ + checks (parts, UV layer, material, min tris, total tris == clean_tris); writes manifests/verify_report.json; exit code 2 on failure.
6. New regression test for thick double-wall shell. 5/5 tests pass (BLENDER-INDEPENDENT-TESTED). Blender stages NOT re-run.

## v2.1.1 (build-integrity patch)
- `build` now refuses a prepared .blend whose geometry no longer matches the prepare stage (triangle count != `vfrb_clean_tris`, or vertices not used by any face). Found when stray geometry (+4 vertices, +3 faces) appeared after manual face assignment; previously a lone loose vertex passed silently and extra faces would have been folded into `body`.
- The "not fully triangulated" error no longer advises rerunning `prepare` (which overwrites the prepared .blend); it explains how to find and remove the stray faces.
- New `validate.mesh_integrity()` with 5 Blender-independent regression tests (suite: 22 tests).

## v2.1.2
- `build` also compares the vertex count with `manifests/prepare_report.json` (`verts_after`). The v2.1.1 check passed a mesh that had been "repaired" by deleting stray faces: triangle count matched again, but 3 extra vertices and 3 extra edges remained and one original triangle had been replaced. `build` now refuses a build when `prepare_report.json` is missing.
- Recovery workflow: transfer face assignments onto the pristine prepared geometry by centroid matching (`vfrb_transfer_regions.py`, not part of the build pipeline).
