# Design references

Visual references for client-facing frontend work. Read with `DESIGN.md` at the repo root. No images are committed yet; add files here as they become available.

## Expected files

1. **Real VFRB garment photos**: actual uniforms made by VFRB (fabric, stitching, fit). These set the photography and colour direction.
2. **3–5 editor screenshots**: Canva, Adobe Express, Figma or Customink-style design editors, showing the gallery-first flow, the contextual floating toolbar and the lit garment stage.
3. **Current VFRB screens**: the Design Studio, client Home (Dashboard) and Order Wizard as they are today, as the baseline to improve on.

## Naming

Use lowercase, hyphenated names grouped by prefix, for example `garment-polo-navy.jpg`, `editor-canva-toolbar.png`, `current-studio-1366.png`.
